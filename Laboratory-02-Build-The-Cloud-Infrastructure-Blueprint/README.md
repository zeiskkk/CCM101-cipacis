## Cloud Infrastructure Components

### Compute

Compute resources provide the processing power needed to run applications, commands, and services. In the KillerCoda environment, the CPU and CPU cores provide the computing power of the Linux server.

### Storage

Storage resources are used to store the operating system, applications, files, and other data. The KillerCoda server uses disk storage for its Linux system and files.

### Networking

Networking resources allow servers, computers, and users to communicate. The KillerCoda environment has network connectivity, a hostname, and an IP address.

### Operating System

The operating system manages the server's hardware and provides an environment for applications and commands to run. KillerCoda provides a Linux-based operating system.
