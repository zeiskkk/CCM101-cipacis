# Cloud Infrastructure Components

## 1. Compute Resources

### Purpose
Compute resources provide the processing power needed to run applications, commands, and services.

### Importance in Cloud Computing
Compute resources are important because cloud applications need processing power to perform tasks. Cloud providers allow organizations to use computing resources without having to maintain physical servers.

### KillerCoda Environment
The KillerCoda Linux server provides CPU resources that can be used to execute Linux commands and perform computing tasks. The CPU model and number of CPU cores were identified during the server investigation.

---

## 2. Storage Resources

### Purpose
Storage resources are used to store the operating system, applications, files, and other data.

### Importance in Cloud Computing
Storage is important because cloud applications need a reliable place to save and access data. Cloud storage also allows organizations to manage their data without depending entirely on local physical storage.

### KillerCoda Environment
The KillerCoda server provides disk storage for the Linux operating system, files, and applications. The available disk capacity and mounted file systems were identified using Linux commands.

---

## 3. Networking Resources

### Purpose
Networking resources allow computers, servers, and users to communicate with each other.

### Importance in Cloud Computing
Networking is important because cloud services need to communicate with users and other services through a network connection. It allows cloud applications and servers to exchange data.

### KillerCoda Environment
The KillerCoda Linux server has networking resources that allow it to communicate over the network. The hostname and IP address were identified during the server investigation.

---

## 4. Operating System

### Purpose
The operating system manages the computer's hardware and provides an environment where applications and commands can run.

### Importance in Cloud Computing
An operating system is important because cloud servers need software that manages their computing resources and allows users and applications to interact with the server.

### KillerCoda Environment
KillerCoda provides a Linux-based operating system. The operating system and kernel version were identified using Linux commands during the investigation.

---

## Summary

The KillerCoda environment demonstrates how compute, storage, networking, and operating system resources work together. The CPU provides processing power, storage keeps data and system files, networking enables communication, and the Linux operating system manages these resources.
