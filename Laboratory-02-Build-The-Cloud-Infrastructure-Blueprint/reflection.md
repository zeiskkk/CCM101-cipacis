# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

I think compute resources are one of the most important cloud infrastructure components because they provide the processing power needed to run applications and services. Without compute resources, other resources such as storage and networking would not be able to support running applications effectively.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a stable and flexible operating system for cloud servers. It allows users and cloud engineers to manage resources, run applications, execute commands, and monitor the server through the terminal.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it records the resources, configurations, and decisions involved in an infrastructure design. It helps engineers understand the system, identify possible problems, and make better decisions before deploying actual cloud services.

## 4. What new skills did you learn during this laboratory activity?

I learned how to investigate a Linux server using commands such as `uname`, `lscpu`, `free`, `df`, `mount`, and `hostname`. I also learned how to identify cloud infrastructure components, compare services from different cloud providers, create a basic cloud architecture diagram, and organize technical documentation using Markdown and GitHub.

## 5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio has become more organized and informative after completing this laboratory activity. I added documentation about Linux server resources, cloud infrastructure components, cloud provider comparisons, and a cloud architecture diagram. This makes my portfolio a better record of the cloud computing skills and knowledge I developed during the laboratory.
