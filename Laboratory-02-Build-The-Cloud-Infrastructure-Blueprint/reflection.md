# Mission Reflection

During this laboratory activity, I learned more about how cloud infrastructure works and how its different components work together. Among these components, I think **compute resources** are one of the most important because they provide the processing power needed to run applications and services. Without them, storage and networking would not be able to fully support an active application. This activity helped me realize that every part of cloud infrastructure has its own purpose and is important in building a working cloud environment.

I also gained a better understanding of how **Linux is used in cloud computing**. Using the Linux environment in KillerCoda, I was able to check important server information such as the operating system, kernel, CPU, RAM, disk space, file systems, hostname, and IP address. Using different Linux commands made me more comfortable working with the terminal and helped me see how cloud servers can be monitored and managed.

Another lesson I learned is the importance of **proper technical documentation** before deploying infrastructure. Having clear documentation makes it easier to understand the system, keep track of configurations, find possible problems, and share information with other team members. It also helps reduce mistakes because the planned setup can be reviewed before making changes.

Throughout the laboratory, I improved my skills in using Linux commands, identifying cloud infrastructure components, comparing AWS, Microsoft Azure, and Google Cloud Platform, creating cloud architecture diagrams, and writing Markdown documentation. These activities gave me a better idea of what a cloud engineer does and the skills needed in this field.

Lastly, I was able to improve my **GitHub portfolio** by adding a complete laboratory folder with my reports, documentation, reflection, screenshots, and architecture diagram. Overall, this activity gave me practical experience and helped me become more familiar with cloud computing.
