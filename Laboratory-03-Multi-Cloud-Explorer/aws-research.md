# Amazon Web Services (AWS) Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform that provides a wide range of cloud services for businesses, organizations, and developers. AWS provides services for computing, storage, databases, networking, security, machine learning, analytics, and application development. Its services allow organizations to build and run applications without having to maintain all of the physical infrastructure themselves.

## Global Infrastructure

AWS operates a global infrastructure made up of geographic Regions and Availability Zones. An AWS Region is a separate geographic area, while Availability Zones are isolated locations within a Region. AWS recommends using multiple Availability Zones when designing highly available applications because a failure in one Availability Zone does not necessarily affect the others.

AWS also provides other infrastructure options such as Local Zones and Wavelength Zones for workloads that need resources closer to users or specific network locations.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. Users can use the console to create and configure resources such as virtual machines, storage buckets, databases, and networking resources.

The console also allows users to select AWS Regions and manage resources according to their location.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides resizable computing capacity through virtual servers. Organizations can use EC2 instances to run websites, applications, development environments, and other workloads.

### 2. Amazon S3

Amazon Simple Storage Service (S3) is an object storage service. It stores files and other data as objects inside buckets and can be used for websites, backups, mobile applications, data lakes, and many other workloads.

### 3. Amazon VPC

Amazon Virtual Private Cloud (VPC) provides a logically isolated virtual network where organizations can launch AWS resources. It allows administrators to configure networking components such as subnets and internet connectivity.

### 4. AWS IAM

AWS Identity and Access Management (IAM) controls access to AWS resources. It allows administrators to manage users, roles, permissions, and policies so that users and applications only receive the access they need.

## Three Advantages

1. **Scalability** – AWS provides resources that can be increased or decreased according to application requirements.

2. **Global Infrastructure** – AWS has a large worldwide infrastructure that allows organizations to deploy applications closer to their users.

3. **Wide Range of Services** – AWS provides services covering computing, storage, networking, databases, security, analytics, artificial intelligence, and other areas.

## Typical Enterprise Use Cases

AWS is commonly used by organizations for hosting websites and applications, storing and backing up data, running databases, building mobile applications, and supporting data analytics and machine learning workloads.

Large organizations can also use AWS to build highly available applications by distributing resources across multiple Availability Zones or Regions.
