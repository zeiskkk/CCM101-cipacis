# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides cloud services for computing, storage, networking, databases, security, artificial intelligence, analytics, and application development. Azure is widely used by organizations that already use Microsoft technologies and need to extend their existing IT infrastructure into the cloud.

## Global Infrastructure

Azure has a global infrastructure consisting of regions and datacenters distributed around the world. Azure provides many regions so organizations can choose locations based on factors such as latency, data residency, compliance, and availability.

Azure Availability Zones are physically and logically separated datacenters within an Azure region. They have independent power, networking, and cooling, which helps organizations design applications with higher availability and resilience.

## Cloud Management Console

The Azure portal is a web-based management interface used to create, configure, monitor, and manage Azure resources.

Administrators can use the portal to manage virtual machines, storage accounts, databases, networks, identities, and other Azure services from a centralized interface.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide scalable virtual computing resources. Organizations can use them to run Windows or Linux applications without purchasing and maintaining physical servers.

### 2. Azure Blob Storage

Azure Blob Storage is an object storage service designed for storing large amounts of unstructured data such as documents, images, videos, logs, and backups.

### 3. Azure Virtual Network

Azure Virtual Network provides private networking for Azure resources. It allows virtual machines and other resources to communicate with each other, the internet, and on-premises networks.

### 4. Microsoft Entra ID

Microsoft Entra ID is a cloud-based identity and access management service. It helps organizations manage users, applications, devices, and access to resources.

## Three Advantages

1. **Microsoft Integration** – Azure works closely with Microsoft technologies such as Microsoft 365, Windows Server, and Microsoft Entra ID.

2. **Global Infrastructure** – Azure provides a large worldwide infrastructure that supports applications requiring global availability and low latency.

3. **Enterprise Features** – Azure provides services for security, identity, networking, databases, artificial intelligence, and hybrid cloud environments.

## Typical Enterprise Use Cases

Azure is commonly used for hosting enterprise applications, migrating Windows Server workloads, storing business data, running databases, supporting hybrid cloud environments, and developing artificial intelligence and analytics applications.

Organizations can also use Azure to connect cloud resources with existing on-premises infrastructure.
