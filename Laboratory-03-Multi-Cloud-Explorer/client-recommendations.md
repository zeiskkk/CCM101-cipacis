# Client Recommendations

## Client A – Startup Company

### Recommended Platform: AWS

AWS is a good choice for the startup because it provides many cloud services that can support a mobile application as it grows. The company can begin with a small amount of computing and storage resources and increase them when the number of users grows. AWS also provides pay-as-you-go cloud services, which can help a startup avoid purchasing expensive physical servers. The startup could use Amazon EC2, Amazon S3, and Amazon RDS for its application.

### Possible Services

- Amazon EC2 – Application computing
- Amazon S3 – File and object storage
- Amazon RDS – Managed relational database

---

## Client B – University

### Recommended Platform: Microsoft Azure

Microsoft Azure is the most appropriate choice because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's existing technologies and can help the university gradually move selected services to the cloud. The university can also use Microsoft Entra ID to manage identities and access. This can make the transition easier for administrators and users who are already familiar with Microsoft products.

### Possible Services

- Azure Virtual Machines – Cloud-based Windows or Linux servers
- Azure Blob Storage – Cloud storage
- Microsoft Entra ID – Identity and access management

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud

Google Cloud is a suitable choice for the AI research company because it provides strong artificial intelligence, machine learning, data analytics, and high-performance computing capabilities. The company can use cloud computing resources to train and run AI models without purchasing all of the required physical hardware. Google Cloud also provides services that support large-scale data processing. The company could use Compute Engine, Google Kubernetes Engine, and Vertex AI.

### Possible Services

- Compute Engine – Virtual computing resources
- Google Kubernetes Engine – Container and Kubernetes management
- Vertex AI – Artificial intelligence and machine learning

---

## Client D – Global E-Commerce Company

### Recommended Platform: AWS

AWS is a suitable choice for a global e-commerce company because it provides services that can support highly available and scalable applications. The company can distribute its application across multiple Availability Zones and use automatic scaling to handle changes in customer traffic. AWS also provides database, networking, and content delivery services that can support a global online store. The company could use Amazon EC2, Auto Scaling, Amazon RDS, and Amazon CloudFront.

### Possible Services

- Amazon EC2 – Application servers
- AWS Auto Scaling – Automatic scaling of resources
- Amazon RDS – Managed database
- Amazon CloudFront – Content delivery
