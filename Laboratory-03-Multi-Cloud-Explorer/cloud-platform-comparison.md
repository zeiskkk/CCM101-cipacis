## Questions

### 1. Which cloud provider offers the broadest range of services?

AWS offers one of the broadest selections of cloud services among the three major providers. It provides services for computing, storage, databases, networking, security, analytics, artificial intelligence, and many other areas.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure provides the strongest integration with Microsoft technologies. It works closely with products such as Windows Server, Microsoft 365, Active Directory, and Microsoft Entra ID.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is a strong choice for Artificial Intelligence, Machine Learning, and Kubernetes. Google Cloud provides AI and data services while Google Kubernetes Engine provides a managed Kubernetes environment.

### 4. Which cloud platform would you personally choose and why?

I would personally choose AWS because it provides a wide variety of cloud services and supports many different types of applications. I also think AWS would be useful for learning because its services can be applied to startups, websites, databases, and enterprise applications.
