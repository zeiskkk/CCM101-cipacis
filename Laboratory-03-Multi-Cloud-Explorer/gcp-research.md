# Google Cloud Platform (GCP) Research

## Brief Overview

Google Cloud Platform (GCP), also known as Google Cloud, is a cloud computing platform provided by Google. It offers services for computing, storage, networking, databases, Kubernetes, artificial intelligence, machine learning, analytics, and application development.

Google Cloud allows organizations to deploy applications and infrastructure using Google's global cloud infrastructure.

## Global Infrastructure

Google Cloud uses a global infrastructure consisting of regions and zones. Regions are geographic locations, while zones are deployment areas within regions. Organizations can distribute workloads across different zones and regions to improve availability and fault tolerance.

Google also operates a global network that connects its cloud infrastructure and helps provide connectivity for applications and users around the world.

## Cloud Management Console

The Google Cloud Console is a web-based interface for managing Google Cloud resources and services. Users can use the console to create and manage virtual machines, storage, databases, networks, Kubernetes clusters, and other cloud resources.

Google Cloud resources can also be managed using tools such as the Google Cloud CLI and APIs.

## Four Core Services

### 1. Compute Engine

Google Compute Engine provides virtual machines and computing resources that run on Google's infrastructure. Organizations can use it for applications, web servers, development environments, and high-performance computing workloads.

### 2. Cloud Storage

Google Cloud Storage is a scalable and managed object storage service. It stores data as objects inside buckets and can be used for application data, backups, media, and other types of information.

### 3. Google Kubernetes Engine

Google Kubernetes Engine (GKE) is a managed Kubernetes service used to deploy, manage, and scale containerized applications.

### 4. Google Cloud VPC

Google Cloud Virtual Private Cloud (VPC) provides networking for cloud resources such as Compute Engine virtual machines and GKE clusters. It provides a global virtual network with regional subnets.

## Three Advantages

1. **Strong Data and AI Capabilities** – Google Cloud provides services for data analytics, artificial intelligence, and machine learning.

2. **Kubernetes Support** – Google Kubernetes Engine provides managed Kubernetes capabilities for organizations using containerized applications.

3. **Global Network** – Google operates a large global network that connects its cloud infrastructure and supports applications deployed around the world.

## Typical Enterprise Use Cases

Google Cloud is commonly used for data analytics, artificial intelligence and machine learning, containerized applications, web applications, databases, and high-performance computing.

Organizations can also use Google Cloud for large-scale data processing and applications that require Kubernetes-based deployment.
