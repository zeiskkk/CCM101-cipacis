Completing this mission helped me understand how virtualization, containerization, and automation work together to build a functional private cloud environment. I used Ubuntu Server 24.04 in VirtualBox and set up SSH access so I could manage the server remotely from Windows Terminal. I then installed Docker and Docker Compose to deploy Nextcloud alongside a MariaDB database.

One of the key lessons was understanding how containers communicate within a shared Docker network. I connected Nextcloud to MariaDB and used persistent volumes to ensure that application files and database data survived container restarts. I also learned how critical it is to configure port forwarding, firewall rules, and network settings correctly, since even small misconfigurations can block access to services.

During implementation, I ran into issues with Docker image downloads and reaching the Nextcloud web interface. Troubleshooting required checking container status, verifying network connectivity, and reviewing VirtualBox port forwarding settings. Another challenge was getting the backup script to run reliably. It initially failed due to Docker command permissions and sudo authentication prompts, which I resolved by configuring Docker group access and adjusting the script to run non-interactively.

I also built a backup script that exports the MariaDB database and archives the Nextcloud data directory. The script enables maintenance mode during the backup, validates the resulting archive, and deletes backups older than seven days. I scheduled it with cron to run daily at 2:00 AM UTC.

Overall, this activity strengthened my understanding of virtualization, containerization, networking, storage, security, and server automation. I learned that deploying a cloud application involves more than making it reachable through a browser—it also requires protecting data, monitoring services, and preparing reliable backups. This project gave me hands-on experience managing a small cloud infrastructure, and the skills I gained will be valuable in future cloud computing activities and IT projects.
